# Minha jornada com Next.js 14

Desenvolver com Next.js 14 tem sido uma experiência transformadora. O App Router trouxe uma nova forma de pensar sobre aplicações React.

## Server Components

A possibilidade de ter componentes que executam no servidor por padrão simplificou muito o fluxo de dados. Não preciso mais buscar dados no cliente para coisas simples.

## Conclusão

Recomendo experimentar Next.js 14 em seus projetos.
